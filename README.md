# Maricica învață să fie curată

Poveste educațională interactivă pentru copii de 3 ani, adaptată după «Maricica» de Luiza Vlădescu.

## Publicare

Aplicația conține `index.html`, `style.css`, `script.js`, ilustrații în `assets/` și fișiere audio în `audio/`. Pentru publicare se încarcă **conținutul dezarhivat** al pachetului în rădăcina depozitului, apoi se activează **Settings → Pages → Deploy from a branch → main → /(root)**.

Resursa nu colectează date despre copii. Verificați drepturile de publicare a înregistrărilor și adaptării literare.
